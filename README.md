# PharmaPulse – Power BI Dashboard

## 📊 Project Overview

PharmaPulse is an interactive pharmaceutical analytics dashboard developed using Microsoft Power BI.

The dashboard provides insights into pharmaceutical sales, inventory levels, customer distribution, geographic performance, and doctor/prescription-related activities.

It is designed to help stakeholders monitor business performance and make data-driven decisions.

## 📌 Dashboard Pages

The dashboard contains five interactive pages:

1. Executive Overview
2. Inventory Analysis
3. Sales Analysis
4. Customer & Geographic Analysis
5. Doctor & Prescription Analysis

## 🚀 Key Features

- Revenue, profit, and sales performance KPIs
- Monthly revenue trend analysis
- Top-performing product analysis
- Inventory and stock-status monitoring
- Sales channel performance comparison
- Customer distribution by city and customer type
- Geographic sales analysis
- Doctor specialty analysis
- Prescription and payment method analysis
- Order status distribution
- Interactive slicers for:
  - Year
  - Country
  - Region
  - Sales Channel
- Synchronized filters across all dashboard pages

## 🛠️ Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning
- Data Visualization
- Business Intelligence

## 📈 Business Insights

This dashboard helps users understand:

- Overall pharmaceutical sales and profitability
- Regional and country-level performance
- Products contributing the most revenue
- Inventory availability and stock risks
- Customer and sales channel behavior
- Doctor specialty and prescription patterns
